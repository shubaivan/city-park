# Ручна перевірка в браузері

Прогін після кожного деплою, що зачіпає адмінку або бота. Займає ~10 хвилин.
Порядок має значення: перевірки, що створюють дані, стоять останніми, і кожна з них
закінчується прибиранням за собою.

**Правило**: на проді не залишаємо сміття. Усе, що створили, — видаляємо або відвʼязуємо
в тому ж кроці. Нічого не блокуємо і не змінюємо статус реальному мешканцю.

## 1. Панель відкривається і з компʼютера, і з телефона

- [ ] `/admin` — обидва розділи в меню: «👤 Люди» і «🏢 Обʼєкти нерухомості».
- [ ] Звузити вікно до ~390 px (або відкрити з телефона): сторінки не їдуть убік,
      текст читається без збільшення, поля вводу при фокусі не зумлять сторінку.
- [ ] `/admin/users` — таблиця згортає колонки, стрілка «▶» ліворуч розкриває рядок.

## 2. Реєстр обʼєктів

- [ ] `/admin/objects` — лічильник угорі збігається з кількістю карток («N з N»).
- [ ] Фільтр «🚗 Паркінг» — лишаються тільки паркомісця, лічильник змінився.
- [ ] Фільтр «❓ Без власника» — у кожній картці червоний рядок «Жоден мешканець не
      привʼязаний».
- [ ] «буд. 19» у другому ряду — лишились обʼєкти лише 19-го будинку.
- [ ] «буд. 19» + «🚗 Паркінг» разом — паркомісця тільки 19-го (фільтри складаються).
- [ ] «Усі будинки» повертає повний список.
- [ ] «👥 2+ власники» — у кожній картці двоє і більше людей.
- [ ] Клік по імені власника відкриває картку цієї людини в розділі «Люди».
- [ ] У картці людини особовий рахунок обʼєкта клікається і веде назад у «Обʼєкти»,
      з підставленим у пошук номером.
- [ ] Пошук за особовим рахунком (напр. `217191`) — одна картка.
- [ ] Пошук за словом «паркомісце» — знаходить (тип теж шукається).
- [ ] Пошук за прізвищем або телефоном власника — знаходить.
- [ ] Телефон власника клікається (`tel:`), `@username` веде в Telegram.
- [ ] Нежитлові підписані правильно: «буд. 19, паркомісце 191», а не «кв. 191».

## 3. Тип обʼєкта

- [ ] Відкрити «🏷 Тип обʼєкта» на будь-якій квартирі — вибраний «🏠 Квартира».
- [ ] Змінити на «🚗 Паркомісце», зберегти → зелене повідомлення, підпис картки став
      «паркомісце N», значок «авто» зник.
- [ ] **Повернути «🏠 Квартира»** — підпис повернувся.

## 4. Група одного власника

- [ ] На обʼєкті A відкрити «🔗 Той самий власник», вписати особовий рахунок обʼєкта B,
      «Привʼязати» → зелене повідомлення.
- [ ] На обох картках зʼявився інший обʼєкт і рядок «Разом по власнику».
- [ ] Лічильник «у групах» угорі виріс на 2.
- [ ] Відкрити картку мешканця, привʼязаного до A: блок «🏢 Обʼєкти цього власника»
      показує свій обʼєкт із міткою «основний» плюс B, і сумарний борг.
- [ ] **Відвʼязати** B → обидва вийшли з групи (група з одного не лишається),
      лічильник «у групах» повернувся до попереднього.

## 5. Створення обʼєкта

- [ ] «➕ Додати обʼєкт»: вписати неіснуючий рахунок, будинок, номер, тип, площу →
      зелене повідомлення, картка зʼявилась, статус «Активний», борг 0, власників 0.
- [ ] Спробувати додати той самий рахунок ще раз → червоне «уже є в базі».
- [ ] **Прибрати за собою**: створений обʼєкт лишається в базі — або одразу видалити його
      через SQL, або створювати тільки тоді, коли обʼєкт справді потрібен.

## 6. Заявки

- [ ] `/admin/complaints` — картки, а не таблиця; видно автора, його телефон (`tel:`) і
      Telegram.
- [ ] «💬 Обговорення» розгорнуте, якщо є повідомлення.
- [ ] Дописати повідомлення → воно зʼявилось у гілці, підписане «Людмила (голова ОСББ)»
      або «ОСББ», **а автору прийшло в Telegram**.
- [ ] Статус «⏸ Відкладено» **без** нотатки → червоне попередження, статус не змінився.
- [ ] Той самий статус із нотаткою → зберігся, нотатка видно як «⏸ Чекає: …».
- [ ] **Повернути початковий статус.**

## 7. Борги

- [ ] `/admin/debt` — унизу «📁 Архів завантажень»; якщо порожній, так і написано.
- [ ] Після завантаження файлу: видно скільки рахунків не знайдено **і на яку суму**,
      під списком — файл у архіві з кнопкою «Завантажити».
- [ ] Завантажений із архіву файл відкривається в Excel.

## 8. Бот (з телефона, не з браузера)

- [ ] «💸 Звіт боржників» — сторінки гортаються ⬅️/➡️, лічильник «Сторінка N з M».
- [ ] Кнопка «📌 Моя квартира» веде на сторінку зі своїм рядком.
- [ ] Свій рядок («ваша квартира — N місце» або «боргів не має») видно на кожній сторінці.
- [ ] Картка заявки: автор бачить «✏️ Змінити текст», «🗑 Видалити», «💬 Обговорення»;
      голова ОСББ додатково бачить контакт автора і «✍️ Написати автору».

## 9. Бекап

```
sudo -u www-data php bin/console db:backup --env=prod
```

- [ ] Три рядки `[OK]`: файл, Telegram, пошта.
- [ ] Файл прийшов у Telegram і на пошту, розмір збігається.
- [ ] `var/log/prod_errors.log` не поповнився.
